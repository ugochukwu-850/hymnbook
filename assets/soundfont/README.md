# SoundFont

`TimGM6mb.sf2` (General MIDI, ~6 MB) by Tim Brechbill, from the MuseScore
project. Licensed **GPL-2** (some samples public domain). Used for organ and
flute playback. Bundling it means distributing the app under GPL-compatible
terms; revisit before any public release (alternatives: a CC0/PD SoundFont).
